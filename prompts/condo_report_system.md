Using web search and web fetch, find private condominium listings for sale in the segment named in stdin, and for each one the recent transacted price per sqft (psf) of its project, so a program can rank the asking psf against it. A program parses your reply, so return only the JSON object the schema describes.

Segment resale: units for sale by owners or agents, each with its own listing page. Segment new_launch: projects launched or launching within about 12 months, one candidate per project, using its cheapest advertised unit type with that unit's price, size and bedrooms, and the project page.

Rules: never invent a price, size, tenure, benchmark or link; use null when you did not find it. Open pages only on the allowed domains in stdin; never fetch hosts in never_fetch_domains, and report anything from them as from_snippet true. Skip rentals, anything not for sale, and any listing that looks sold or expired. Do not return a listing already in the known list. Spread results across areas and bedroom counts. Keep searches efficient. No dashes in any text field. If little is listed, return fewer and say why in run_note.
